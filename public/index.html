NGINX2Root: Remote Code Execution vulnerabilities in nginx

Nov 18, 2026 16:13 | Source: lwn.net

Xint is reporting that it has discovered a collection of five critical vulnerabilities in the NGINX web server. The worst flaw, it says, would allow an unauthenticated attacker to execute commands on an affected nginx server with HTTP/2 enabled. The company also reports a local-privilege escalation (LPE) kernel vulnerability, which was introduced in the 4.15 kernel, in the Stream Control Transmission Protocol (SCTP) subsystem. If chained with the NGINX vulnerability, it would allow an attacker to gain root privileges on the host. A kernel patch for this is not yet available. We also obtained a root shell on the host in a setup where nginx was running in a Docker container. On many Linux distributions, the SCTP module is installed by default and the kernel loads it automatically the first time a program opens an SCTP socket. Whether SCTP is reachable on a given host still depends on the kernel, the available modules, and the container's restrictions. Where it is reachable, the attacker can take over the host kernel. Since all containers on the host share that kernel, this gives the attacker control of the host and every container on it. Xint recommends updating to NGINX 1.31.9, which was just released, and to block the SCTP module on hosts that do not need it until a kernel fix is available. See the mitigations section of their report for more information.

Voyager 1 Reaches One Light-Day From Earth

NASA's Voyager 1 has become the first human-made object to travel one light-day from Earth, or 16,094,799,096 miles (25,902,068,356 kilometers). This means radio signals will take 24 hours to reach the spacecraft, now nearly 50 years into its mission. "Since light is essentially the maximum speed in the universe (absent using devices like wormholes, or quantum-physics puzzles), it's a big deal -- so big that NASA will be celebrating the milestone by asking fans to shine Morse Code signals at the sky," reports Space.com. From the report: But why will Voyager 2 take nearly a decade longer? It comes down to choices made for speed and science during the twin missions' nearly 50-year journey, specifically during the first bit when they were flying by planets. The result is Voyager 1 is zooming out at a speed of 3.5 Earth-sun distances (astronomical units a year), while Voyager 2 has a more stately speed of 3.1 Earth-sun distances, according to NASA. [...] At any rate, these fast speeds allowed both spacecraft not only to go fast, but to eventually reach interstellar space in 2012 (Voyager 1) and 2018 (Voyager 2), respectively. With the light-day milestone now reached by Voyager 1, it is anticipated the spacecraft could work into the 2030s, as long as their nuclear power sources can last. NASA's Jet Propulsion Laboratory, which manages the mission, has been carefully turning off instruments as required, and recently did a "Big Bang" procedure on both spacecraft to redistribute power supplies as best as possible. Two decades ago, this privacy concern was more firmly embedded in the public consciousness, but it has since faded considerably.
