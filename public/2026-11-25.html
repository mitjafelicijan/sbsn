BleepingComputer reports: The researchers track the activity as GT13 and confirmed it was ongoing between October 17 and November 2, when their visibility ended. However, given the threat actor's persistent access to Check Point devices, they believe the campaign remains active. GreyNoise says the 22 victim organizations are spread across 17 countries, and show no clear evidence of specific targeting. They include government entities, financial services providers, and companies in the energy, transportation, mining, and manufacturing sectors. The attacks were launched from 99 IP addresses that appear to come from compromised Check Point devices and ExpressVPN exit nodes. A Rejetto HTTP File Server, compromised by exploiting CVE-2026-61500, was used as an operational relay for managing intrusions and collecting stolen data from the compromised environments. While GreyNoise could not determine when or how the Check Point servers were breached, it observed the exploitation of CVE-2026-16232 during the post-compromise stages. The vulnerability is an authentication bypass in Check Point SmartConsole that allows attackers to obtain an application login token and authenticate with administrator privileges. Check Point warned about the flaw in July, marking it as an actively exploited zero-day. The researchers also observed attempts to exploit CVE-2025-5777 (Citrix NetScaler), CVE-2024-21893 (Ivanti), CVE-2026-41089 (Windows NetLogon), CVE-2026-16232 (Check Point SmartConsole auth bypass to Run Script), and CVE-2026-98432 (Linux IPv4 UAF). Nov 24, 2026 17:00 | Source: linuxjournal.com

by George Whittaker Valve has released Proton 11.0-3, a substantial update to its open-source compatibility layer for running Windows games on Linux and SteamOS. Released on November 24, 2026, the latest stable version expands compatibility to 15 additional games, introduces experimental support for 32-bit OpenXR applications, improves controller functionality, and addresses numerous graphics, audio, and performance problems affecting both modern and older titles. The release also resolves several regressions introduced during the transition to Proton 11, including memory leaks under KDE Plasma's Wayland session, fullscreen window-management problems, and compatibility issues affecting AMD processors and graphics cards. These improvements are accompanied by updates to several foundational components, including DXVK, VKD3D-Proton, Wine Mono, Xalia, and the FEX instruction translation framework. For Linux desktop gamers and Steam Deck owners, Proton 11.0-3 represents a meaningful improvement to everyday gaming reliability. Rather than concentrating exclusively on adding new titles, Valve continues refining the underlying technologies responsible for making Windows games behave naturally within a Linux environment. Expanding the Reach of Windows Gaming on Linux Proton has become one of the most important components of the modern Linux gaming ecosystem. Originally introduced by Valve in 2018, the compatibility layer combines Wine with specialized graphics translation libraries and game-specific modifications to allow Windows applications to execute on Linux without requiring a separate Windows installation. The software translates Windows application programming interfaces into functionality available through Linux and its supporting libraries. Graphics operations are frequently translated into Vulkan through DXVK and VKD3D-Proton, while other components handle Windows-specific input devices, multimedia functions, networking, and application behavior. What makes Proton particularly useful is its integration with Steam. Users can install and launch many Windows games directly from their libraries without manually configuring Wine environments or installing individual compatibility components. Steam manages much of the underlying configuration, including the creation of separate Wine prefixes for individual games. Proton 11.0-3 continues improving this experience by addressing compatibility problems that might otherwise prevent games from launching, displaying graphics correctly, recognizing controllers, or functioning reliably during extended gameplay.
